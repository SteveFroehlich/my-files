## 2026-05-14

#### Interactive Platforms & Hubs

- **Civitai:** Primary hub for open-source AI art models, ComfyUI workflows, and active creator forums. Like hugging face but just for art
- **Discord Servers:** Join specialized servers like _Stable Diffusion_, _ComfyUI Community_, and _OpenArt AI_ for real-time troubleshooting.
- **Reddit Communities:** Subscribe to r/comfyui, r/StableDiffusion, and r/DigitalArt for daily workflow sharing and critique. 

Advanced Workflow Sharing

- **OpenArt.ai Workflows:** Browse, download, and execute advanced node-based ComfyUI setups created by other artists.
- **ComfyUI Workflows (GitHub):** Search curated repositories to find noodle-art templates for specific style animations.
- **ComfyUI Node Registry (CMH):** Install custom nodes via the ComfyUI Manager to access cutting-edge community tools. 

Traditional & Hybrid Art Networks

- **ArtStation:** Standard professional portfolio site currently expanding to include advanced technical and procedural art pipelines.
- **Cara:** Fast-growing, artist-first platform specifically built for traditional digital illustrators seeking an AI-regulated space.
- **Cara & Mastodon Links:** Build cross-platform networks by linking your specialized node workflows back to your main portfolio.

#### Shaders
Inspired by Manim interest:

- **Shadertoy:** A massive community centered entirely around writing pixel shaders (GLSL) to create mind-bending, math-driven 3D visuals.
- **The Book of Shaders:** An interactive online guide that teaches you how to program fragment shaders from scratch.
- **Inigo Quilez Blogs:** Essential technical reading by the co-creator of Shadertoy, focusing on signed distance functions (SDFs) and procedural noise

#### Generative logic

- **OpenProcessing:** A social platform for sketching with p5.js and Processing, allowing you to inspect, fork, and edit any artist's code instantly.
- **Coding Train (Daniel Shiffman):** The definitive learning ecosystem for algorithmic art, physics simulations, and cellular automata

#### Transformer understanding

- **Transformer Explainer:** Created by researchers at Georgia Tech, Transformer Explainer lets you see a live decoder-only GPT model run in your browser. It visualizes tokenization, Query-Key-Value (QKV) matrix calculations, and multi-head attention mechanisms layer by layer.
- **LLM Visualization (bbycroft):** An incredible 3D interactive model rendering cell-by-cell matrix multiplication, softmax operations, and residual network pathways as a data structure tree.
- **AnimatedLLM:** A web application available via AnimatedLLM on GitHub that generates step-by-step visual trace paths of token arrays traversing open LLM architectures


#### Open source implementation platforms

- **Andrej Karpathy’s llm.c / nanoGPT:** The gold standard community repository for software engineers. The discussion boards and forks focus on writing raw C/CUDA and PyTorch code to implement transformer blocks cleanly without massive framework overhead.
- **Hugging Face TGI & vLLM GitHub Discussions:**These repositories house the engineers optimizing PagedAttention and Mixture-of-Experts (MoE) routing matrices. Participating here exposes you to production-level LLM system design constraints like throughput, latency, and memory memory bandwidth
